# Rebirth Game engine

C++20 Game engine

## Features (could be broken)
* Vulkan backend
* PBR (without IBL)
* Shadow maps
* Skeleton animations (vertex skinning)
* Physics engine integration using Jolt Physics
* Dynamic rendering (vulkan)
* Multisampling (MSAA)
* Mip map generation
* glTF scene loader
* Dear ImGui integration for custom tooling
* Tracy profiler

## Third party libraries
* SDL3
* glm
* Dear ImGui
* cgltf
* stb
* volk
* VulkanMemoryAllocator
* Jolt Physics
* tracy
